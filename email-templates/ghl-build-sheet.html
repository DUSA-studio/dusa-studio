SaaS welcome email — build sheet

Rebuilding New SaaS Client email (Location) in DUSA branding, by hand in the GHL builder.

Finished article to work from: dusa.studio/email/saas-welcome-preview.html

Read this before you start. Your template is MJML output, and it carries only four CSS classes across the whole document. There are no per-block hooks, so Custom CSS cannot colour block 4 differently from block 7. It can only do global things and section-level things.

So the split is: set every colour, size and padding in each block's own panel (reliable, and it survives you reordering things later), and use the Custom CSS below only for the two things the panels do not expose. Do not try to do the whole design in CSS.

Step 1 — Paste the Custom CSS

Styles panel → Custom CSS. Replace the empty <style> with this. I tested these selectors against your actual template markup, so they land.

<style> /* DUSA . studio — SaaS welcome email Only the bits the block panels cannot do. Everything else is set per block. */ /* Letter-spacing is not exposed in the builder panels. These two selectors give the wordmark and the small uppercase eyebrows their brand tracking. */ .dusa-wordmark, .dusa-wordmark * { letter-spacing: 2.4px !important; text-transform: uppercase !important; } .dusa-eyebrow, .dusa-eyebrow * { letter-spacing: 1.6px !important; text-transform: uppercase !important; } /* Frame colour behind the 600px email body. */ .email-content { background-color: #EDE9E3 !important; } /* Stop Gmail and Outlook.com recolouring the address in the footer. */ .email-content a[href^="mailto"] { color: #4ED8C2 !important; text-decoration: none !important; } /* Tighten the side padding on phones so the copy is not a narrow ribbon. */ @media only screen and (max-width: 480px) { .email-content td { padding-left: 22px !important; padding-right: 22px !important; } } </style>
The two class names above need attaching. If your text blocks have an advanced or custom-class field, put dusa-wordmark on the two DUSA . STUDIO blocks and dusa-eyebrow on the two small uppercase lines. If there is no such field, skip it. You lose only the letter-spacing, and you can fake it by typing the wordmark with spaces: D U S A . S T U D I O.

Step 4 — Before you save

The merge fields are load-bearing. Check every one of these survived, spelled exactly like this. A typo here does not throw an error, it just silently sends a broken email.
  • {{user.passwordUrl}} on both buttons
  • {{user.first_name}} in the headline and the account panel
  • {{user.last_name}} and {{user.email}} in the account panel
  • {{agency.name}} in the account panel and the footer
  • {{agency.email}} and {{right_now.year}} in the footer
  1. Hit Preview and check the desktop and mobile toggles.
  2. Send yourself a test. Open it on a phone, and in Outlook if you have it.
  3. Click the button in the test to confirm the activation link resolves.
What will not survive Outlook on Windows. It uses the Word rendering engine, so rounded corners go square and some of the Custom CSS is ignored. Nothing breaks, it just looks plainer. Every colour and all the copy still come through, because those are set per block rather than in CSS. That is exactly why the split above is worth keeping.
